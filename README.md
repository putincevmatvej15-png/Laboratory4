# Лабораторная работа №4. Последовательные одномерные контейнеры

## Описание

Изучение алгоритмов формирования и обработки одномерных массивов и
последовательных контейнеров, программирование и отладка программ
формирования и обработки массивов.

Использование контейнеров **строго обязательно** как для C++, так и для
других языков. Все поэлементные циклы с постоянным шагом должны быть
**range-based for** (C++11+).

Материалы: <https://en.cppreference.com/w/cpp/language/range-for>

## Задания

**Задание 1. Нелинейные уравнения.** Для уравнения `f(x) = 0` по варианту:
1. Отделить графически все корни.
2. Составить методики решения для метода половинного деления,
   метода Ньютона и метода простых итераций.
3. Реализовать метод половинного деления с точностью `ε` и выводом
   таблицы `n | aₙ | bₙ | bₙ − aₙ`.
4. Реализовать методы Ньютона и простых итераций с точностью `ε`
   и выводом таблицы `n | xₙ | xₙ₊₁ | xₙ₊₁ − xₙ`.
5. Найти все корни уравнения с верными знаками.
6. Сравнить методы по скорости сходимости.

Вариант уравнения — из таблицы 2 методички.

**Задание 2. Вычисления в массивах.** По варианту реализовать набор
операций над массивом с использованием алгоритма генерации из таблицы 3
(`ranlux48`, `knuth_b`, `random_device`, `minstd_rand`, `mt19937`,
`mt19937_64`, `ranlux24_base`, `ranlux48_base`, `ranlux24`).
Например, для варианта 1:
- массив из `n ≥ 10` случайных чисел в `[0, 100]`;
- обмен минимального и второго максимального элементов;
- сдвиг массива по образцу;
- подсчёт чётных и сумма нечётных;
- вывод «змейкой» по 10 элементов.

**Задание 3. Генераторы ПСЧ.** По варианту реализовать один из алгоритмов
из таблицы 4:
- вариант 1 — RC4;
- вариант 2 — Xorshift;
- вариант 3 — генератор Фибоначчи с запаздыванием;
- вариант 4 — BBS (квадратичный остаток);
- вариант 5 — линейный конгруэнтный генератор.

Для ЛКГ — вывести последовательность и индекс начала повторения.

**Задание 4. Теория голосований.** `n` кандидатов, `k` избирателей,
каждый избиратель задаёт полное ранжирование. Определить победителя:
- **метод Борда** — баллы за позицию `(n−1, n−2, …, 0)`, побеждает
  набравший больше всех;
- **метод Кондорсе** — попарные сравнения, побеждает кандидат,
  выигрывающий у всех остальных.

Вывести победителя по каждому методу; если результаты разнятся —
прокомментировать. Протестировать на крайних случаях (все голоса
одинаковые; победителя Кондорсе не существует).
